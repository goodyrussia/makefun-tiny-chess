A chess engine in 4 KB of Python: 0x88 board, negamax alpha-beta with quiescence search, a transposition table and killer moves, iterative deepening to depth 6. It plays the make.fun gauntlet over the HTTP env.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
